# Skill: Seed Synthetic Jira Dataset

This skill generates and populates the database with realistic synthetic Jira sprint data for offline testing, demos, and verification.

## Dataset Characteristics

- **Program Scope**: 4 cross-functional squads (Checkout Squad, Mobile Team, Platform Team, Analytics Team).
- **Milestones**: M0 (Foundation), M1 (Alpha), M2 (Beta), M3 (GA).
- **Embedded Scenarios**:
  - Realistic velocity variations across sprints.
  - Dependency conflict test cases (e.g. cross-sprint blocker chains).
  - Sprint overcommitment edge cases.
